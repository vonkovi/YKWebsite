SIM42 is a distributed, agent-based simulation built to study how economies, hierarchies, and norms emerge from many independent minds. Every one of 100+ language-model agents starts from the *same* immutable objective — "accumulate coins" — and everything interesting downstream (trade, reputation, coalitions) is emergent, not scripted.

### The PIANO loop

Agents don't run on a global tick. Each one is split into a non-LLM **Sensor** (interrupt-driven), an **Orchestrator** that only calls the model on a deliberate decision, and **Tools** for actions. The payoff is economic: an idle or sleeping agent costs *zero* compute, so the model is spent only where a real choice happens.

### The day is the clock

The in-game day is the fundamental time unit, and sleep is the natural synchronization barrier. Each morning an agent rebuilds a mutable "sense of self" with a single reflection call — which is how identical prompts diverge into distinct strategies over a hundred simulated days.

### Running it on GKE

Three engines — **World**, **God**, **State** — run as separate services on Google Kubernetes Engine, with **one pod per agent** and per-agent `asyncio` loops inside. They coordinate over **Cloud Pub/Sub**; **Firestore** holds agent state; a live **WebSocket** feed drives a Phaser/TypeScript dashboard so you can watch factions form in real time.

### Personality and energy

Hidden **Big Five** multipliers scale the energy cost of every action, so agents express temperament purely through behavior — never by reading their own scores. Energy depletes with action and recovers only through sleep, which turns "rest" into a real constraint rather than flavor text.

### What stuck

The hard limit was compute cost, not cleverness. The first cut paid a full LLM call for every agent on every tick — about two minutes per tick — so the entire v2 design is one idea: make idleness free. At this scale, the infrastructure **is** the experiment.
